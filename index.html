How to Practise Listening

Follow these five proven steps to build comprehension, pronunciation, and speaking fluency.

  1. 1

    Listen to the audio without reading the passage.

  2. 2

    Listen again while following the written text.

  3. 3

    Pause after each sentence and repeat it aloud.

  4. 4

    Compare British and American versions.

  5. 5

    Practise shadowing to improve fluency and intonation.

Project Source Files & Deployment Guide

Split frontend files ready for a GitHub Pages repository (index.html, style.css, script.js).

Separate Cloudflare Workers backend (worker.js) using the Gemini Interactions REST API (gemini-3.8-flash-tts).

1. Set Up the Gemini API Key

  1. Sign in to Google AI Studio (https://aistudio.google.com/).
  2. Open Get API key and create an API key in your Google Cloud project.
  3. Verify that gemini-3.8-flash-tts is enabled and check your project quota/billing tier for classroom traffic.

2. Configure the Cloudflare Worker

  1. Install Wrangler CLI or create a Worker in the Cloudflare Dashboard: npm create cloudflare@latest english-tts-worker (choose Hello World JS Worker).
  2. Replace src/index.js (or worker.js) with the complete worker.js code from the Project 2: Backend tab.
  3. Update DEFAULT_ALLOWED_ORIGIN in worker.js (or set ALLOWED_ORIGIN in wrangler.toml) to your exact GitHub Pages origin, e.g. https://your-username.github.io.
  4. Deploy with npx wrangler deploy and note the generated https://...workers.dev URL.

3. Add the Two Cloudflare Secrets

  1. Never store credentials in wrangler.toml or frontend code. Run these commands in your Worker directory:
  2. npx wrangler secret put GEMINI_API_KEY → paste your Google AI Studio API key.
  3. npx wrangler secret put CLASS_ACCESS_CODE → enter the classroom passcode you will share with students.
  4. Alternatively, add both encrypted variables in Cloudflare Dashboard → Workers & Pages → Your Worker → Settings → Variables and Secrets.

4. Connect the Frontend to the Worker URL

  1. In script.js, edit STUDIO_CONFIG.WORKER_URL to your deployed https://...workers.dev URL.
  2. You can also test immediately inside this page by clicking Backend URL in the header and saving your Worker URL.

5. Deploy the Frontend via GitHub Pages

  1. Create a public GitHub repository (for example, english-tts-studio).
  2. Upload index.html, style.css, and script.js to the root of the main branch.
  3. Go to Repository Settings → Pages → Build and deployment, select Deploy from a branch, choose main / /(root), and save.
  4. Open https://your-username.github.io/english-tts-studio/ and verify ALLOWED_ORIGIN on the Worker matches https://your-username.github.io.
